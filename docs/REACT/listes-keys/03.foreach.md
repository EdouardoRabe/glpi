## Introduction

`forEach()` parcourt un tableau pour executer une action sur chaque element. Il ne retourne pas de nouveau tableau.

## Syntaxe

```js
tableau.forEach((element, index, tableauOriginal) => {
  // action
});
```

## Exemples simples

```js
const nombres = [1, 2, 3];
let somme = 0;

nombres.forEach((n) => {
  somme += n;
});
// somme = 6
```

```js
const users = [
  { id: 1, nom: "Alya" },
  { id: 2, nom: "Bruno" }
];

users.forEach((u) => {
  console.log(u.nom);
});
```

## Quand utiliser forEach

Utilisez `forEach()` pour:

- Journaliser, accumuler, ou declencher des effets de bord.
- Mettre a jour un etat externe ou appeler une API.

Si vous avez besoin d un nouveau tableau, utilisez `map()`.

## Erreurs courantes

- Attendre un retour de `forEach()` (il retourne `undefined`).
- Utiliser `forEach()` avec `await` en pensant qu il attend les promesses.
- Modifier un tableau pendant l iteration sans precaution.

Exemple d attente incorrecte:

```js
const result = [1, 2, 3].forEach((n) => n * 2);
// result est undefined
```

## Checklist rapide

- `forEach()` ne retourne rien.
- Utilise pour les effets de bord, pas pour transformer.
- Evite l `async/await` dans un `forEach()` si l ordre est important.
