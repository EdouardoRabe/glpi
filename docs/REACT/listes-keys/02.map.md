## Introduction

`map()` transforme un tableau en un nouveau tableau. Chaque element passe dans une fonction qui retourne la nouvelle valeur.

## Syntaxe

```js
const nouveauTableau = tableau.map((element, index, tableauOriginal) => {
  return nouvelleValeur;
});
```

Version courte:

```js
const nouveauTableau = tableau.map((element) => nouvelleValeur);
```

## Exemples simples

```js
const nombres = [1, 2, 3];
const doubles = nombres.map((n) => n * 2);
// [2, 4, 6]
```

```js
const users = [
  { id: 1, nom: "Alya" },
  { id: 2, nom: "Bruno" }
];
const noms = users.map((u) => u.nom);
// ["Alya", "Bruno"]
```

## Utilisation avec React

```jsx
function Liste({ items }) {
  return (
    <ul>
      {items.map((item) => (
        <li key={item.id}>{item.label}</li>
      ))}
    </ul>
  );
}
```

## Erreurs courantes

- Oublier de retourner une valeur dans la fonction `map()`.
- Modifier le tableau d origine au lieu de retourner un nouveau tableau.
- Utiliser `map()` pour des effets de bord (preferez `forEach()`).
- Oublier la `key` en React lors d un rendu de liste.

## Checklist rapide

- `map()` retourne toujours un nouveau tableau.
- La fonction de rappel retourne une valeur.
- Pas d effets de bord dans `map()`.
