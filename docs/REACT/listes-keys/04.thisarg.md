## Introduction

`map()` et `forEach()` acceptent un second parametre facultatif: `thisArg`. Il permet de definir la valeur de `this` a l interieur de la fonction de rappel.

## Syntaxe

```js
array.map(callbackFn, thisArg)
array.forEach(callbackFn, thisArg)
```

```js
array.map(function (element) {
  return this.prefixe + element;
}, objetThis)
```

## Comment fonctionne thisArg

- `thisArg` fixe la valeur de `this` pour la fonction de rappel.
- Si vous utilisez une **fonction flechee**, `thisArg` est ignore, car les fonctions flechees n ont pas leur propre `this`.
- En mode strict, sans `thisArg`, `this` vaut `undefined` dans la fonction.

## Exemples avec map

```js
const outils = ["marteau", "scie"];
const contexte = { prefixe: "outil: " };

const etiquettes = outils.map(function (item) {
  return this.prefixe + item;
}, contexte);
// ["outil: marteau", "outil: scie"]
```

## Exemples avec forEach

```js
const notes = [10, 12, 14];
const stats = { total: 0 };

notes.forEach(function (n) {
  this.total += n;
}, stats);

// stats.total = 36
```

## Erreurs courantes

- Utiliser `thisArg` avec une fonction flechee et s attendre a ce que `this` change.
- Oublier le mode strict et penser que `this` pointe sur un objet global.
- Confondre `thisArg` avec un parametre normal de la fonction.

Mauvais exemple:

```js
const ctx = { prefixe: "x-" };
const result = ["a"].map((item) => this.prefixe + item, ctx);
// this est lexical, ctx est ignore
```

## Checklist rapide

- `thisArg` fonctionne uniquement avec des fonctions classiques.
- Les fonctions flechees ignorent `thisArg`.
- En cas de doute, preferer une fonction classique.
