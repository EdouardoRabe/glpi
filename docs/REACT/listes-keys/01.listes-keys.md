## Introduction

En React, afficher une liste se fait generalement avec `map()`. Pour que React puisse mettre a jour la liste efficacement, chaque element doit avoir une `key` unique et stable.

## Rendre une liste avec map

```jsx
const fruits = [
  { id: "a1", nom: "Pomme" },
  { id: "b2", nom: "Banane" },
  { id: "c3", nom: "Cerise" }
];

function ListeFruits() {
  return (
    <ul>
      {fruits.map((fruit) => (
        <li key={fruit.id}>{fruit.nom}</li>
      ))}
    </ul>
  );
}
```

## Pourquoi les keys sont importantes

- React compare les elements d une liste pour savoir quoi ajouter, supprimer, ou mettre a jour.
- Une `key` stable aide React a conserver le bon etat des composants.
- De bonnes keys evitent des re-rendus inutiles et des bugs d interface.

## Choisir une bonne key

Une bonne `key` doit etre:

- **Unique** dans la liste.
- **Stable** dans le temps.
- **Derivee d un identifiant reel** (id de base de donnees, slug, uuid).

Exemple recommande:

```jsx
<li key={produit.id}>{produit.nom}</li>
```

## Cas ou l index peut convenir

Utiliser l index du tableau (`map((item, index) => ...)`) n est acceptable que si:

- La liste est **statique** (pas d ajout, suppression, tri).
- L ordre ne change jamais.

Dans le doute, evitez l index.

## Exemples pratiques

### Liste dynamique avec suppression

```jsx
function TodoList({ todos, onRemove }) {
  return (
    <ul>
      {todos.map((todo) => (
        <li key={todo.id}>
          {todo.texte}
          <button onClick={() => onRemove(todo.id)}>Supprimer</button>
        </li>
      ))}
    </ul>
  );
}
```

### Mauvais exemple: index comme key

```jsx
{todos.map((todo, index) => (
  <li key={index}>{todo.texte}</li>
))}
```

Probleme: si vous supprimez un element, React peut confondre les lignes et reutiliser de mauvais etats.

## Erreurs courantes

- Utiliser une `key` qui change a chaque rendu (`Math.random()`, `Date.now()`).
- Utiliser l index sur des listes dynamiques.
- Oublier la `key` sur un element rendu via `map()`.

## Checklist rapide

- Chaque element d une liste a une `key`.
- Les `keys` viennent d un identifiant stable.
- Pas de `Math.random()` ou `Date.now()` pour les `keys`.
- Pas d index si la liste peut changer.
