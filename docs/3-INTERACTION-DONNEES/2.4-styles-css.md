# 2.4 Styles & CSS Intégration

## QUOI ?

**CSS en React** = plusieurs approches pour styliser des composants (global, inline, modules, CSS-in-JS).

---

## POURQUOI ?

- ✅ Styliser l'interface selon les besoins
- ✅ Styles dynamiques basés sur le state
- ✅ Éviter les conflits de noms CSS
- ✅ Responsive design et thèmes

---

## COMMENT ?

### Approche 1 : CSS Global (simple)

**App.css**
```css
.button {
  background-color: blue;
  color: white;
  padding: 10px 20px;
  border: none;
  border-radius: 5px;
  cursor: pointer;
}

.button:hover {
  background-color: darkblue;
}
```

**App.jsx**
```jsx
import './App.css'

function App() {
  return <button className="button">Clique</button>
}

export default App
```

⚠️ Les styles s'appliquent **globalement**.

### Approche 2 : Inline Styles (dynamique)

```jsx
function Bouton() {
  const styles = {
    backgroundColor: 'blue',   // camelCase !
    color: 'white',
    padding: '10px 20px',
    border: 'none',
    borderRadius: '5px',
    cursor: 'pointer'
  }

  return <button style={styles}>Clique</button>
}

export default Bouton
```

✅ Facile pour styles dynamiques  
❌ Pas de `:hover`, pas de media queries

### Approche 3 : CSS Modules (isolé)

**Button.module.css**
```css
.button {
  background-color: blue;
  color: white;
  padding: 10px 20px;
}

.button:hover {
  background-color: darkblue;
}

.primary {
  background-color: green;
}
```

**Button.jsx**
```jsx
import styles from './Button.module.css'

function Button({ primary }) {
  return (
    <button className={`${styles.button} ${primary ? styles.primary : ''}`}>
      Clique
    </button>
  )
}

export default Button
```

✅ Styles isolés par composant  
✅ Supporte `:hover`, media queries  
✅ Aucun conflit

### Approche 4 : Styles dynamiques avec state

```jsx
import { useState } from 'react'

function ThemeToggle() {
  const [isDark, setIsDark] = useState(false)

  const bgColor = isDark ? '#333' : '#fff'
  const textColor = isDark ? '#fff' : '#000'

  return (
    <div style={{ backgroundColor: bgColor, color: textColor, padding: '20px' }}>
      <p>Mode: {isDark ? '🌙 Sombre' : '☀️ Clair'}</p>
      <button onClick={() => setIsDark(!isDark)}>
        Basculer le thème
      </button>
    </div>
  )
}

export default ThemeToggle
```

### Approche 5 : Classes conditionnelles

```jsx
import { useState } from 'react'
import './Button.css'

function Button() {
  const [isActive, setIsActive] = useState(false)

  return (
    <button 
      className={isActive ? 'button active' : 'button'}
      onClick={() => setIsActive(!isActive)}
    >
      {isActive ? 'Actif' : 'Inactif'}
    </button>
  )
}

export default Button
```

**Button.css**
```css
.button {
  background-color: gray;
  padding: 10px 20px;
}

.button.active {
  background-color: green;
}
```

## Cas courants

### Classes conditionnelles avec librairie

```bash
npm install classnames
```

```jsx
import classNames from 'classnames'

function Button({ primary, disabled }) {
  const className = classNames('btn', {
    'btn-primary': primary,
    'btn-disabled': disabled
  })

  return <button className={className}>Clique</button>
}
```

## Comparatif des approches

| Approche | Avantage | Inconvénient |
|----------|----------|-------------|
| Global | Simple, universel | Conflits possibles |
| Inline | Dynamique facile | Pas de `:hover`, verbose |
| Modules | Isolé, sûr | Setup requis |
| Tailwind | Très rapide | Classes longues |
| styled-components | Puissant | Dépendance externe |

---

## camelCase pour les propriétés CSS

| CSS standard | React |
|---|---|
| `background-color` | `backgroundColor` |
| `font-size` | `fontSize` |
| `border-radius` | `borderRadius` |
| `margin-bottom` | `marginBottom` |
| `padding-left` | `paddingLeft` |
