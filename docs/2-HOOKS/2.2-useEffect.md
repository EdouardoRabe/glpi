# 2.2 - useEffect (Effets Secondaires)

## QUOI ?
`useEffect` permet d'exécuter du code **après** que le composant se soit rendu. C'est pour faire des choses qui ne sont pas du pur rendu: appels API, modifications du DOM, timers, subscriptions, etc.

## POURQUOI ?
- Faire des appels à une API après le rendu
- Mettre à jour le titre de la page
- S'abonner à des événements externes
- Nettoyer les ressources (memory leaks)
- Synchroniser avec des systèmes externes

## COMMENT ?

### Une Seule Fois au Montage

```jsx
import { useEffect } from 'react';

function Component() {
  useEffect(() => {
    console.log('Composant monté (une seule fois)');
  }, []);  // [] = dépendances vides = UNE FOIS
  
  return <div>Mon composant</div>;
}
```

### À Chaque Rendu

```jsx
function Component() {
  useEffect(() => {
    console.log('Le composant s\'est rendu!');
  });  // Pas de dépendances = à CHAQUE rendu
  
  return <div>Mon composant</div>;
}
```

### Quand une Dépendance Change

```jsx
import { useEffect, useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);
  
  useEffect(() => {
    console.log('Le count a changé:', count);
  }, [count]);  // S'exécute seulement si count change
  
  return (
    <div>
      <p>Compte: {count}</p>
      <button onClick={() => setCount(count + 1)}>+</button>
    </div>
  );
}
```

### Fonction de Nettoyage (Cleanup)

**Très important pour éviter les memory leaks:**

```jsx
function Timer() {
  useEffect(() => {
    const interval = setInterval(() => {
      console.log('Tick...');
    }, 1000);
    
    // Cette fonction s'exécute AVANT le re-render ou au démontage
    return () => {
      clearInterval(interval);  // Nettoyer!
    };
  }, []);
  
  return <div>Timer (regardez la console)</div>;
}
```

### Appel API - Fetch

```jsx
import { useEffect, useState } from 'react';

function UserList() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);
  
  useEffect(() => {
    const fetchUsers = async () => {
      try {
        const response = await fetch('https://api.example.com/users');
        const data = await response.json();
        setUsers(data);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    };
    
    fetchUsers();
  }, []);  // Une seule fois
  
  if (loading) return <p>Chargement...</p>;
  if (error) return <p>Erreur: {error}</p>;
  
  return (
    <ul>
      {users.map(user => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}
```

### Écouter les Événements Globaux

```jsx
function WindowSizeListener() {
  useEffect(() => {
    const handleResize = () => {
      console.log('Largeur:', window.innerWidth);
    };
    
    // S'inscrire
    window.addEventListener('resize', handleResize);
    
    // Se désinscrire (nettoyage)
    return () => {
      window.removeEventListener('resize', handleResize);
    };
  }, []);
  
  return <div>Redimensionnez la fenêtre</div>;
}
```

### Mettre à Jour le Titre

```jsx
function NotificationCounter() {
  const [count, setCount] = useState(0);
  
  useEffect(() => {
    document.title = `Notifications (${count})`;
  }, [count]);  // À chaque fois que count change
  
  return (
    <button onClick={() => setCount(count + 1)}>
      Ajouter notification
    </button>
  );
}
```

## Exemple Complet: Horloge en Temps Réel

```jsx
import { useEffect, useState } from 'react';

function Clock() {
  const [time, setTime] = useState(new Date());
  
  useEffect(() => {
    const interval = setInterval(() => {
      setTime(new Date());
    }, 1000);
    
    return () => clearInterval(interval);
  }, []);
  
  return <h2>{time.toLocaleTimeString()}</h2>;
}
```

## Exemple Complet: Recherche avec Debounce

```jsx
import { useEffect, useState } from 'react';

function SearchUsers() {
  const [search, setSearch] = useState('');
  const [results, setResults] = useState([]);
  
  useEffect(() => {
    if (!search) {
      setResults([]);
      return;
    }
    
    // Attendre 500ms après le dernier caractère
    const timer = setTimeout(() => {
      fetch(`https://api.github.com/search/users?q=${search}`)
        .then(res => res.json())
        .then(data => setResults(data.items || []))
        .catch(() => setResults([]));
    }, 500);
    
    // Nettoyer le timer si l'utilisateur tape encore
    return () => clearTimeout(timer);
  }, [search]);
  
  return (
    <div>
      <input 
        placeholder="Chercher sur GitHub..."
        value={search}
        onChange={(e) => setSearch(e.target.value)}
      />
      <ul>
        {results.map(user => (
          <li key={user.id}>{user.login}</li>
        ))}
      </ul>
    </div>
  );
}
```

## Ordre d'Exécution

```jsx
function Example() {
  console.log('1. Rendu du composant');
  
  useEffect(() => {
    console.log('2. useEffect [] (montage)');
    return () => console.log('4. Cleanup');
  }, []);
  
  useEffect(() => {
    console.log('3. useEffect sans [] (à chaque rendu)');
  });
  
  return <div>Mon composant</div>;
}

// Ordre d'exécution:
// 1. Rendu du composant
// 2. useEffect [] (montage)
// 3. useEffect sans [] (à chaque rendu)
```

## Pièges Courants

❌ **Oublier la fonction de cleanup pour les intervals**
```jsx
// ❌ FUITE MÉMOIRE!
useEffect(() => {
  setInterval(() => console.log('Tick'), 1000);
});

// ✅ Correct - nettoyer
useEffect(() => {
  const interval = setInterval(() => console.log('Tick'), 1000);
  return () => clearInterval(interval);
});
```

❌ **Appel API sans dépendances**
```jsx
// ❌ Appel infini!
useEffect(() => {
  fetch('/api/data').then(res => res.json());
  // Pas de [], donc s'exécute à chaque rendu
});

// ✅ Une seule fois
useEffect(() => {
  fetch('/api/data').then(res => res.json());
}, []);
```

❌ **Oublier une dépendance**
```jsx
const userId = props.userId;

// ❌ Va utiliser un ancien userId!
useEffect(() => {
  fetch(`/api/user/${userId}`);
}, []);  // userId manque!

// ✅ Ajouter la dépendance
useEffect(() => {
  fetch(`/api/user/${userId}`);
}, [userId]);
```

## À Retenir ✨

- ✅ `useEffect(() => {}, [])` = une seule fois au montage
- ✅ `useEffect(() => {}, [dep])` = quand dep change
- ✅ `useEffect(() => {})` = à chaque rendu
- ✅ `return () => { }` = nettoyage (essentiellement!)
- ✅ Les appels API doivent être dans useEffect
- ✅ TOUJOURS nettoyer les events/timers/subscriptions
