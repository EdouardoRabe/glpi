# 2.1 - useState (État Réactif)

## QUOI ?
`useState` est le premier Hook React. Il permet à un composant d'avoir une "mémoire". C'est comment on crée des données qui changent et qui mettent à jour l'affichage quand elles changent.

## POURQUOI ?
- Les props sont statiques (ne changent pas)
- Avec `useState`, on peut avoir des données **dynamiques**
- Quand l'état change, le composant se re-rend automatiquement
- C'est LA fondation de la réactivité React

## COMMENT ?

### Syntaxe Basique

```jsx
import { useState } from 'react';

function Counter() {
  // useState retourne une paire: [valeur, fonction pour la modifier]
  const [count, setCount] = useState(0);
  
  return (
    <div>
      <p>Compte: {count}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
    </div>
  );
}
```

**Explication:**
- `useState(0)` = initialiser l'état à 0
- `count` = la valeur actuelle de l'état
- `setCount` = la fonction pour changer l'état
- Quand on appelle `setCount(valeur)`, React re-rend le composant

### Plusieurs États

```jsx
function UserForm() {
  const [name, setName] = useState('');
  const [age, setAge] = useState('');
  const [email, setEmail] = useState('');
  
  return (
    <form>
      <input 
        value={name} 
        onChange={(e) => setName(e.target.value)}
        placeholder="Nom"
      />
      <input 
        value={age} 
        onChange={(e) => setAge(e.target.value)}
        placeholder="Âge"
      />
      <input 
        value={email} 
        onChange={(e) => setEmail(e.target.value)}
        placeholder="Email"
      />
      
      <p>Infos: {name}, {age} ans, {email}</p>
    </form>
  );
}
```

### État avec Objet

```jsx
function UserForm() {
  const [user, setUser] = useState({
    name: '',
    age: '',
    email: ''
  });
  
  const handleChange = (field, value) => {
    // Important: créer un NOUVEL objet
    setUser({
      ...user,                    // Copier les valeurs existantes
      [field]: value             // Changer juste celle demandée
    });
  };
  
  return (
    <form>
      <input 
        value={user.name} 
        onChange={(e) => handleChange('name', e.target.value)}
        placeholder="Nom"
      />
      <p>Infos: {user.name}</p>
    </form>
  );
}
```

### État avec Array

```jsx
function TodoList() {
  const [todos, setTodos] = useState(['Faire les courses']);
  
  const addTodo = (newTodo) => {
    setTodos([...todos, newTodo]);  // Ajouter un élément
  };
  
  const removeTodo = (index) => {
    setTodos(todos.filter((_, i) => i !== index));  // Supprimer
  };
  
  return (
    <div>
      <ul>
        {todos.map((todo, i) => (
          <li key={i}>
            {todo}
            <button onClick={() => removeTodo(i)}>❌</button>
          </li>
        ))}
      </ul>
      <button onClick={() => addTodo('Nouvelle tâche')}>Ajouter</button>
    </div>
  );
}
```

### Initialisation Lazy (Coûteuse)

```jsx
function ExpensiveComponent() {
  const [count, setCount] = useState(() => {
    console.log('Calcul lourd une seule fois...');
    return 0;  // Exécuté UNE FOIS au démarrage
  });
  
  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>+</button>
    </div>
  );
}
```

## Exemple Complet: Lampe

```jsx
function Lamp() {
  const [isOn, setIsOn] = useState(false);
  
  const toggleLamp = () => {
    setIsOn(!isOn);  // Inverser la valeur
  };
  
  return (
    <div className={`lamp ${isOn ? 'on' : 'off'}`}>
      <button onClick={toggleLamp}>
        {isOn ? 'Éteindre' : 'Allumer'}
      </button>
      <p>La lampe est {isOn ? '✨ ALLUMÉE' : 'éteinte'}</p>
    </div>
  );
}
```

## Mise à Jour Basée sur la Valeur Précédente

```jsx
function Counter() {
  const [count, setCount] = useState(0);
  
  // ❌ MAUVAIS - utilise la valeur de l'état au moment du rendu
  const increment = () => setCount(count + 1);
  
  // ✅ BON - utilise toujours la valeur précédente
  const incrementCorrect = () => setCount(prev => prev + 1);
  
  return (
    <>
      <p>{count}</p>
      <button onClick={incrementCorrect}>+ (Correct)</button>
    </>
  );
}
```

## Pièges Courants

❌ **Modifier l'état directement**
```jsx
// ❌ MAUVAIS
const [count, setCount] = useState(0);
count = count + 1;  // React ne détecte pas!

// ✅ BON
setCount(count + 1);
```

❌ **Oublier spread pour les objets**
```jsx
const [user, setUser] = useState({ name: 'Alice', age: 28 });

// ❌ Écrase tout
setUser({ name: 'Bob' });  // age disparaît!

// ✅ Correct
setUser({ ...user, name: 'Bob' });
```

❌ **Utiliser useState dans une boucle**
```jsx
// ❌ JAMAIS faire ça
for (let i = 0; i < 3; i++) {
  const [count, setCount] = useState(0);  // ERREUR!
}

// ✅ Utiliser un array
const [counts, setCounts] = useState([0, 0, 0]);
```

## À Retenir ✨

- ✅ `const [value, setValue] = useState(initialValue)`
- ✅ Toujours importer: `import { useState } from 'react'`
- ✅ Ne JAMAIS modifier directement, utiliser le setter
- ✅ Pour objets/arrays, utiliser spread `...`
- ✅ Utiliser `prev => ...` pour accéder à la valeur précédente
- ✅ Initialisation lazy avec une fonction si c'est coûteux
