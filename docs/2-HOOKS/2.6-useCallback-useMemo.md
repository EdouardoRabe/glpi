# 2.6 - useCallback & useMemo (Optimisation de Performance)

## QUOI ?
- **useCallback**: Mémorise une fonction pour qu'elle ne change pas si ses dépendances ne changent pas
- **useMemo**: Mémorise une valeur calculée pour éviter les calculs répétés

## POURQUOI ?
- Éviter les re-rendus inutiles
- Perdre les références à des fonctions
- Optimiser un composant qui reçoit des props fonctionnelles
- Éviter des calculs coûteux à répétition

## COMMENT ?

### useCallback - Mémoriser une Fonction

```jsx
import { useCallback, useState } from 'react';

function Parent() {
  const [count, setCount] = useState(0);
  
  // ❌ MAUVAIS - nouvelle fonction à chaque rendu
  const handleClick = () => {
    console.log('Clicked');
  };
  
  // ✅ BON - mémoriser la fonction
  const handleClickMemo = useCallback(() => {
    console.log('Clicked');
  }, []);  // Ne crée une nouvelle fonction que si les dépendances changent
  
  return (
    <Child onClick={handleClickMemo} />
  );
}
```

### Problème Résolu: Fonctions Comme Props

```jsx
// AVANT: L'enfant se re-rend à chaque fois
function Parent() {
  const [count, setCount] = useState(0);
  
  // Nouvelle fonction à chaque rendu!
  const handleClick = () => console.log(count);
  
  return <Child onClick={handleClick} />;  // L'enfant voit une nouvelle fonction
}

function Child({ onClick }) {
  console.log('Child re-rendu');  // S'affiche à chaque rendu du parent
  return <button onClick={onClick}>Cliquez</button>;
}

// APRÈS: Utiliser useCallback
import { useCallback, memo } from 'react';

function Parent() {
  const [count, setCount] = useState(0);
  
  const handleClick = useCallback(() => {
    console.log(count);
  }, [count]);  // Ne change que si count change
  
  return <Child onClick={handleClick} />;
}

// Mémoriser l'enfant aussi
const Child = memo(({ onClick }) => {
  console.log('Child re-rendu');  // Moins souvent maintenant
  return <button onClick={onClick}>Cliquez</button>;
});
```

### useMemo - Mémoriser une Valeur

```jsx
import { useMemo, useState } from 'react';

function ExpensiveComponent() {
  const [count, setCount] = useState(0);
  
  // ❌ MAUVAIS - recalculé à chaque rendu
  const expensiveValue = calculateExpensiveValue(count);
  
  // ✅ BON - mémoriser le calcul
  const memoExpensiveValue = useMemo(() => {
    return calculateExpensiveValue(count);
  }, [count]);  // Recalcul seulement si count change
  
  return <p>{memoExpensiveValue}</p>;
}

function calculateExpensiveValue(n) {
  console.log('Calcul lourd...');
  let sum = 0;
  for (let i = 0; i < n * 1000000; i++) {
    sum += i;
  }
  return sum;
}
```

## Exemple Complet: Liste Triée avec useMemo

```jsx
import { useMemo, useState } from 'react';

function UserList() {
  const [users, setUsers] = useState([
    { id: 1, name: 'Alice', age: 28 },
    { id: 2, name: 'Bob', age: 24 },
    { id: 3, name: 'Charlie', age: 32 }
  ]);
  
  const [sortBy, setSortBy] = useState('name');
  
  // Mémoriser le tri - ne recalculer que si users ou sortBy change
  const sortedUsers = useMemo(() => {
    console.log('Tri en cours...');
    const sorted = [...users];
    
    if (sortBy === 'name') {
      sorted.sort((a, b) => a.name.localeCompare(b.name));
    } else if (sortBy === 'age') {
      sorted.sort((a, b) => a.age - b.age);
    }
    
    return sorted;
  }, [users, sortBy]);
  
  return (
    <div>
      <button onClick={() => setSortBy('name')}>Trier par Nom</button>
      <button onClick={() => setSortBy('age')}>Trier par Âge</button>
      
      <ul>
        {sortedUsers.map(user => (
          <li key={user.id}>{user.name} - {user.age} ans</li>
        ))}
      </ul>
    </div>
  );
}
```

## Exemple Complet: Filtre & Recherche Optimisée

```jsx
import { useMemo, useState, useCallback } from 'react';

function SearchableList() {
  const [items, setItems] = useState([
    'Apple', 'Banana', 'Cherry', 'Date', 'Eggplant'
  ]);
  const [searchTerm, setSearchTerm] = useState('');
  const [sortAsc, setSortAsc] = useState(true);
  
  // Mémoriser le filtrage ET le tri
  const filteredAndSorted = useMemo(() => {
    console.log('Filtrage et tri...');
    
    let result = items.filter(item =>
      item.toLowerCase().includes(searchTerm.toLowerCase())
    );
    
    result.sort((a, b) => {
      const comparison = a.localeCompare(b);
      return sortAsc ? comparison : -comparison;
    });
    
    return result;
  }, [items, searchTerm, sortAsc]);
  
  // Mémoriser le handler
  const handleToggleSort = useCallback(() => {
    setSortAsc(prev => !prev);
  }, []);
  
  return (
    <div>
      <input 
        value={searchTerm}
        onChange={(e) => setSearchTerm(e.target.value)}
        placeholder="Chercher..."
      />
      
      <button onClick={handleToggleSort}>
        Trier {sortAsc ? '↑' : '↓'}
      </button>
      
      <ul>
        {filteredAndSorted.map(item => (
          <li key={item}>{item}</li>
        ))}
      </ul>
    </div>
  );
}
```

## Quand Utiliser useMemo?

```jsx
// ✅ OUI - Calcul coûteux
const sorted = useMemo(() => heavySort(array), [array]);

// ✅ OUI - Utiliser comme prop dependency
const config = useMemo(() => ({ a: 1, b: 2 }), []);
<Child config={config} />  // L'enfant ne re-rend que si config change

// ❌ NON - Calcul simple (overhead > bénéfice)
const doubled = useMemo(() => count * 2, [count]);  // Pas besoin!

// ❌ NON - État normal
const [name, setName] = useState('Alice');  // Pas besoin de useMemo
```

## Quand Utiliser useCallback?

```jsx
// ✅ OUI - Fonction passée à un enfant mémorisé
const handleClick = useCallback(() => setCount(c => c + 1), []);
<MemoChild onClick={handleClick} />

// ✅ OUI - Fonction dans une dépendance de useEffect
useEffect(() => {
  fetchData();
}, [fetchData]);  // fetchData doit être stable

// ❌ NON - Fonction locale uniquement
const handleClick = () => alert('Hi');  // Pas besoin!
return <div onClick={handleClick}>Click</div>;
```

## Analyse de Performance: memo()

```jsx
import { memo } from 'react';

// Envelopper un composant pour éviter le re-render si props ne change pas
const Button = memo(({ label, onClick }) => {
  console.log('Button re-rendu');
  return <button onClick={onClick}>{label}</button>;
});

// Sans memo: re-rend à chaque fois que le parent re-rend
// Avec memo: re-rend seulement si label ou onClick change
```

## Pièges Courants

❌ **Oublier les dépendances useCallback**
```jsx
// ❌ Fermeture stale (old count!)
const handleClick = useCallback(() => {
  console.log(count);  // count peut être un ancien valeur!
}, []);  // ← Oublié count!

// ✅ Correct
const handleClick = useCallback(() => {
  console.log(count);
}, [count]);
```

❌ **Utiliser useMemo partout**
```jsx
// ❌ Suroptimisation
const name = useMemo(() => 'Alice', []);
const age = useMemo(() => 28, []);

// ✅ Faire juste sur les calculs coûteux
const sorted = useMemo(() => expensiveSort(array), [array]);
```

❌ **Ne pas mémoriser le Provider value**
```jsx
// ❌ Nouvelle référence à chaque rendu
function App() {
  const value = { user, setUser };
  return <Context.Provider value={value}><App /></Context.Provider>;
}

// ✅ Mémoriser
const value = useMemo(() => ({ user, setUser }), [user]);
return <Context.Provider value={value}><App /></Context.Provider>;
```

## À Retenir ✨

- ✅ `useCallback` mémorise les **fonctions**
- ✅ `useMemo` mémorise les **valeurs** calculées
- ✅ Utiliser surtout pour les calculs coûteux et les props
- ✅ Ne pas suroptimiser - le overhead peut être pire!
- ✅ `memo()` empêche les re-rendus inutiles
- ✅ Les dépendances sont **critiques**
