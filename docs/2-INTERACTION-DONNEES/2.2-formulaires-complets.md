# 2.2 Formulaires Complets

## QUOI ?

**Formulaires en React** = les champs sont contrôlés par l'état du composant. React maîtrise la valeur affichée ET la soumission.

```jsx
const [email, setEmail] = useState('')

return (
  <input 
    value={email}
    onChange={(e) => setEmail(e.target.value)}
  />
)
```

---

## POURQUOI ?

- ✅ **Source unique de vérité** : l'état React = la valeur du formulaire
- ✅ **Validation facile** : contrôle total sur les données
- ✅ **Soumission contrôlée** : aucune rechargement de page
- ✅ **Feedback utilisateur** : afficher les erreurs immédiatement

---

## COMMENT ?

### Modèle réutilisable

```jsx
import { useState } from 'react'

function MonFormulaire() {
  const [formData, setFormData] = useState({ nom: '', email: '' })

  const handleChange = (e) => {
    const { name, value } = e.target
    setFormData({ ...formData, [name]: value })
  }

  const handleSubmit = (e) => {
    e.preventDefault()  // ← Empêche le rechargement de page
    console.log(formData)
  }

  return (
    <form onSubmit={handleSubmit}>
      <input name="nom" value={formData.nom} onChange={handleChange} />
      <input name="email" value={formData.email} onChange={handleChange} />
      <button type="submit">Envoyer</button>
    </form>
  )
}

export default MonFormulaire
```

## EXEMPLES

### Exemple 1 : Formulaire d'inscription simple

```jsx
import { useState } from 'react'

function Inscription() {
  const [form, setForm] = useState({
    nom: '',
    email: '',
    password: ''
  })

  const handleChange = (e) => {
    const { name, value } = e.target
    setForm({ ...form, [name]: value })
  }

  const handleSubmit = (e) => {
    e.preventDefault()
    console.log('Inscription:', form)
    // Envoyer à une API
  }

  return (
    <form onSubmit={handleSubmit}>
      <h2>Inscription</h2>

      <input 
        type="text"
        name="nom"
        placeholder="Nom"
        value={form.nom}
        onChange={handleChange}
        required
      />

      <input 
        type="email"
        name="email"
        placeholder="Email"
        value={form.email}
        onChange={handleChange}
        required
      />

      <input 
        type="password"
        name="password"
        placeholder="Mot de passe"
        value={form.password}
        onChange={handleChange}
        required
      />

      <button type="submit">S'inscrire</button>
    </form>
  )
}

export default Inscription
```

### Exemple 2 : Formulaire avec validation

```jsx
import { useState } from 'react'

function Contact() {
  const [form, setForm] = useState({ email: '', message: '' })
  const [errors, setErrors] = useState({})

  const handleChange = (e) => {
    const { name, value } = e.target
    setForm({ ...form, [name]: value })
  }

  const valider = () => {
    const newErrors = {}
    if (!form.email) newErrors.email = 'Email requis'
    if (!form.email.includes('@')) newErrors.email = 'Email invalide'
    if (!form.message) newErrors.message = 'Message requis'
    if (form.message.length < 10) newErrors.message = 'Minimum 10 caractères'
    return newErrors
  }

  const handleSubmit = (e) => {
    e.preventDefault()
    const newErrors = valider()
    
    if (Object.keys(newErrors).length === 0) {
      console.log('Formulaire valide:', form)
    } else {
      setErrors(newErrors)
    }
  }

  return (
    <form onSubmit={handleSubmit}>
      <h2>Nous contacter</h2>

      <input 
        type="email"
        name="email"
        placeholder="Email"
        value={form.email}
        onChange={handleChange}
      />
      {errors.email && <p style={{ color: 'red' }}>{errors.email}</p>}

      <textarea 
        name="message"
        placeholder="Message"
        value={form.message}
        onChange={handleChange}
      />
      {errors.message && <p style={{ color: 'red' }}>{errors.message}</p>}

      <button type="submit">Envoyer</button>
    </form>
  )
}

export default Contact
```

## Validation

### Format simple

```jsx
const validerEmail = (email) => {
  const regex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/
  return regex.test(email)
}

const validerPassword = (password) => {
  return password.length >= 8
}
```

### Résumé des validations courantes

| Champ | Validation |
|-------|-----------|
| Email | Contient `@` et `.` |
| Password | Minimum 8 caractères |
| Téléphone | 10 chiffres (France) |
| URL | Commence par `http://` ou `https://` |
| Numéro | Pas de lettres |

## Pièges courants

### ❌ Oublier `value` et `onChange`

```jsx
// ❌ Champ figé (lecture seule)
<input placeholder="Nom" />

// ✅ Champ contrôlé
<input 
  value={nom}
  onChange={(e) => setNom(e.target.value)}
/>
```

### ❌ Oublier `preventDefault()` sur submit

```jsx
// ❌ La page se recharge !
const handleSubmit = (e) => {
  console.log(form)  // Jamais exécuté si rechargement trop rapide
}

// ✅ Empêche le rechargement
const handleSubmit = (e) => {
  e.preventDefault()
  console.log(form)
}
```

### ❌ Mélanger checkbox et value

```jsx
// ❌ ERREUR : checked et value ne se mélangent pas
<input 
  type="checkbox"
  value={accepte}  // ❌ Mauvais
/>

// ✅ BON : utilise checked
<input 
  type="checkbox"
  checked={accepte}  // ✅ Correct
  onChange={(e) => setAccepte(e.target.checked)}
/>
```
