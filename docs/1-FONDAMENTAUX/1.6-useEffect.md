# 1.6 - useEffect (Effets Secondaires)

## QUOI ?
`useEffect` est un Hook React qui permet d'exécuter du code **après** que le composant se soit rendu. C'est pour faire des choses qui ne sont pas du pur rendu: appels API, modifications du DOM, inscriptions/désabonnements, etc.

## POURQUOI ?
- Faire des appels à une API après le rendu
- Mettre à jour le titre de la page
- S'abonner à des événements externes
- Nettoyer les ressources (timers, connexions, etc.)

## COMMENT ?

### useEffect Basique - S'exécute à chaque rendu

```jsx
import { useEffect } from 'react';

function Component() {
  useEffect(() => {
    console.log('Le composant s\'est rendu!');
  });
  
  return <div>Mon composant</div>;
}
// * S'exécute après CHAQUE rendu
```

### useEffect avec Dépendances Vides - Une seule fois

```jsx
import { useEffect } from 'react';

function Component() {
  useEffect(() => {
    console.log('Le composant s\'est monté (une seule fois)');
  }, []);  // Dependency array vide = s'exécute UNE FOIS au montage
  
  return <div>Mon composant</div>;
}
```

### useEffect avec Dépendances - S'exécute si elles changent

```jsx
import { useEffect, useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);
  
  useEffect(() => {
    console.log('Le count a changé:', count);
  }, [count]);  // S'exécute seulement si 'count' change
  
  return (
    <div>
      <p>Compte: {count}</p>
      <button onClick={() => setCount(count + 1)}>+</button>
    </div>
  );
}
```

### Retourner une Fonction de Nettoyage

Très important pour éviter les fuites mémoire:

```jsx
import { useEffect } from 'react';

function Timer() {
  useEffect(() => {
    const interval = setInterval(() => {
      console.log('Tick...');
    }, 1000);
    
    // Cette fonction s'exécute AVANT le re-render ou au démontage
    return () => {
      clearInterval(interval);  // Nettoyer l'interval
    };
  }, []);
  
  return <div>Voir la console</div>;
}
```

### Fetch API - Appel asynchrone

```jsx
import { useEffect, useState } from 'react';

function UserList() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);
  
  useEffect(() => {
    const fetchUsers = async () => {
      try {
        const response = await fetch('https://api.example.com/users');
        const data = await response.json();
        setUsers(data);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    };
    
    fetchUsers();
  }, []);  // Une seule fois au montage
  
  if (loading) return <p>Chargement...</p>;
  if (error) return <p>Erreur: {error}</p>;
  
  return (
    <ul>
      {users.map(user => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}
```

### Écouter les Événements Globaux

```jsx
import { useEffect } from 'react';

function WindowSizeListener() {
  useEffect(() => {
    const handleResize = () => {
      console.log('Nouvelle largeur:', window.innerWidth);
    };
    
    // S'inscrire à l'événement
    window.addEventListener('resize', handleResize);
    
    // Nettoyage: se désinscrire
    return () => {
      window.removeEventListener('resize', handleResize);
    };
  }, []);
  
  return <div>Redimensionnez la fenêtre (vérifiez la console)</div>;
}
```

### Mettre à Jour le Titre de la Page

```jsx
import { useEffect, useState } from 'react';

function NotificationCounter() {
  const [notificationCount, setNotificationCount] = useState(0);
  
  useEffect(() => {
    document.title = `Notifications (${notificationCount})`;
  }, [notificationCount]);
  
  return (
    <div>
      <button onClick={() => setNotificationCount(notificationCount + 1)}>
        Ajouter une notification
      </button>
    </div>
  );
}
```

## Exemple Complet: Horloge en Temps Réel

```jsx
import { useEffect, useState } from 'react';

function Clock() {
  const [time, setTime] = useState(new Date());
  
  useEffect(() => {
    const interval = setInterval(() => {
      setTime(new Date());
    }, 1000);
    
    return () => clearInterval(interval);
  }, []);
  
  return (
    <div className="clock">
      <h2>{time.toLocaleTimeString()}</h2>
    </div>
  );
}
```

## Exemple Complet: Fetcher des Données avec Recherche

```jsx
import { useEffect, useState } from 'react';

function SearchUsers() {
  const [search, setSearch] = useState('');
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(false);
  
  useEffect(() => {
    if (!search) {
      setUsers([]);
      return;
    }
    
    setLoading(true);
    
    const timer = setTimeout(() => {
      fetch(`https://api.github.com/search/users?q=${search}`)
        .then(res => res.json())
        .then(data => setUsers(data.items || []))
        .finally(() => setLoading(false));
    }, 500);  // Débouncer: attendre 500ms après le dernier caractère
    
    return () => clearTimeout(timer);
  }, [search]);
  
  return (
    <div>
      <input 
        value={search}
        onChange={(e) => setSearch(e.target.value)}
        placeholder="Chercher un utilisateur GitHub..."
      />
      
      {loading && <p>Chargement...</p>}
      
      <ul>
        {users.map(user => (
          <li key={user.id}>
            <img src={user.avatar_url} alt={user.login} width="30" />
            {user.login}
          </li>
        ))}
      </ul>
    </div>
  );
}
```

## Ordre d'Exécution - Important!

```jsx
function Example() {
  console.log('1. Composant se rend');
  
  useEffect(() => {
    console.log('2. useEffect avec [] (après le rendu)');
    return () => {
      console.log('5. Nettoyage (avant redémonter)');
    };
  }, []);
  
  useEffect(() => {
    console.log('3. useEffect sans dépendance (après CHAQUE rendu)');
  });
  
  return <div>Je m'affiche</div>;
}

// Ordre:
// 1. Composant se rend
// 2. useEffect avec [] (après le rendu)
// 3. useEffect sans dépendance (après CHAQUE rendu)
```

## Pièges Courants

❌ **ERREUR**: Oublier la fonction de nettoyage pour les intervals

```jsx
// ❌ Mauvais - Crée une fuite mémoire!
useEffect(() => {
  setInterval(() => {
    console.log('Tick');
  }, 1000);
}, []);  // L'interval ne s'arrête JAMAIS!

// ✅ Bon - Nettoyer l'interval
useEffect(() => {
  const interval = setInterval(() => {
    console.log('Tick');
  }, 1000);
  return () => clearInterval(interval);
}, []);
```

❌ **ERREUR**: Faire un appel API sans dépendances

```jsx
// ❌ Fait des appels à l'infini!
useEffect(() => {
  fetch('/api/data')
    .then(res => res.json())
    .then(data => setData(data));
  // Pas de [], donc s'exécute à CHAQUE rendu!
});

// ✅ Une seule fois
useEffect(() => {
  fetch('/api/data')
    .then(res => res.json())
    .then(data => setData(data));
}, []);  // [] = une seule fois au montage
```

❌ **ERREUR**: Modifier l'état directement dans useEffect sans condition

```jsx
// ❌ Crée une boucle infinie!
useEffect(() => {
  setCount(count + 1);  // Cause un re-render qui re-trigger useEffect...
});

// ✅ Ajouter une dépendance
useEffect(() => {
  setCount(count + 1);
}, []);  // [] = s'exécute UNE FOIS
```

## À Retenir ✨

- ✅ `useEffect` s'exécute **après** le rendu
- ✅ `useEffect(() => {}, [])` = une seule fois au montage
- ✅ `useEffect(() => {}, [dep])` = quand dep change
- ✅ `return () => { }` = nettoyage (très important!)
- ✅ Les appels API devraient être dans useEffect
- ✅ Les events globaux doivent être nettoyés
