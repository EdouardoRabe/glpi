# 1.2 - JSX & Syntaxe

## QUOI ?
JSX est une syntaxe qui mélange HTML et JavaScript. Elle permet d'écrire du code qui ressemble à du HTML directly dans nos fichiers JavaScript/React.

## POURQUOI ?
- JSX est plus lisible que `React.createElement()`
- Permet une meilleure organisation et structure du code
- Les outils can compiler JSX en JavaScript ordinaire

## COMMENT ?

### JSX vs JavaScript classique

**Avec JSX** (ce qu'on préfère):
```jsx
const element = <h1>Bonjour le monde!</h1>;
```

**Sans JSX** (compliqué):
```javascript
const element = React.createElement('h1', null, 'Bonjour le monde!');
```

### Insérer des Variables avec des Accolades `{}`

```jsx
const nom = "Alice";
const age = 25;

const greeting = <h1>Bonjour {nom}, tu as {age} ans</h1>;
```

Résultat: `<h1>Bonjour Alice, tu as 25 ans</h1>`

### Expressions JavaScript dans JSX

```jsx
const nombre = 5;

// Opérations mathématiques
<p>2 + 2 = {2 + 2}</p>

// Conditions ternaires
<p>Status: {nombre > 0 ? "Positif" : "Négatif"}</p>

// Appels de fonction
<p>Résultat: {Math.sqrt(16)}</p>

// Concaténation strings
<p>{"Bonjour " + nom}</p>
```

### Attributs HTML dans JSX

```jsx
// Les attributs qui ont des tirets se transforment en camelCase
<label htmlFor="username">Nom:</label>   // for → htmlFor
<input className="input" />              // class → className
<img data-id="123" />                    // Les data attributes restent pareils

// Valeurs dynamiques
const id = "user-123";
<div id={id}></div>

// Styles inline (objet JavaScript)
const styles = {
  color: "blue",
  fontSize: "18px"
};
<h1 style={styles}>Styled Text</h1>

// Ou directement
<h1 style={{ color: "red", padding: "10px" }}>Texte rouge</h1>
```

### Commentaires dans JSX

```jsx
// Les commentaires classiques fonctionnent HORS du JSX
const element = (
  <div>
    {/* Mais dans le JSX, il faut utiliser cette syntaxe */}
    <p>Ceci est visible</p>
    {/* <p>Ceci est commenté et invisible</p> */}
  </div>
);
```

### Fragments - Retourner Plusieurs Éléments

```jsx
// ❌ ERREUR - React n'aime pas plusieurs éléments au même niveau
return (
  <h1>Titre</h1>
  <p>Paragraphe</p>
);

// ✅ Solution: Wrapper dans un div
return (
  <div>
    <h1>Titre</h1>
    <p>Paragraphe</p>
  </div>
);

// ✅ Meilleure Solution: Utiliser un Fragment <>
return (
  <>
    <h1>Titre</h1>
    <p>Paragraphe</p>
  </>
);
```

### JSX doit retourner UN SEUL élément racine

```jsx
// ❌ Erreur
return (
  <Header />
  <Main />
  <Footer />
);

// ✅ Correct
return (
  <>
    <Header />
    <Main />
    <Footer />
  </>
);
```

## Exemple Complet

```jsx
export default function Profile() {
  const user = {
    name: "Alice",
    age: 28,
    city: "Paris"
  };

  return (
    <div className="profile">
      <h2>Profil Utilisateur</h2>
      <p>Nom: {user.name}</p>
      <p>Âge: {user.age}</p>
      <p>Ville: {user.city}</p>
      
      {user.age >= 18 ? (
        <p>Cet utilisateur est majeur</p>
      ) : (
        <p>Cet utilisateur est mineur</p>
      )}
    </div>
  );
}
```

## Pièges Courants

❌ **Erreur**: `className` utilisé comme `class`
```jsx
// ❌ Mauvais
<div class="container"></div>

// ✅ Correct (JSX utilise camelCase)
<div className="container"></div>
```

❌ **Erreur**: Utiliser du HTML directement au lieu de JSX
```jsx
// ❌ Mauvais - C'est juste un string
return "<h1>Bonjour</h1>";

// ✅ Correct - C'est du JSX
return <h1>Bonjour</h1>;
```

❌ **Erreur**: Oublier les accolades pour les variables
```jsx
const nom = "Alice";

// ❌ Mauvais - Affiche "[object Object]" ou le texte littéral
return <p>Bonjour nom</p>;

// ✅ Correct
return <p>Bonjour {nom}</p>;
```

❌ **Erreur**: Plusieurs éléments sans wrapper
```jsx
// ❌ Erreur: "Adjacent JSX elements must be wrapped"
return (
  <Header />
  <Content />
);

// ✅ Correct avec Fragment
return (
  <>
    <Header />
    <Content />
  </>
);
```

## À Retenir ✨

- ✅ JSX permet d'écrire du HTML directement dans le JavaScript
- ✅ Les variables se mettent entre `{}`
- ✅ `className` à la place de `class`
- ✅ Les attributs avec tirets deviennent camelCase
- ✅ Pour plusieurs éléments, utiliser `<>` et `</>`
- ✅ JSX compile en `React.createElement()`
