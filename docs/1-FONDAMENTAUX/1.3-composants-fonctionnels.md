# 1.3 - Composants Fonctionnels

## QUOI ?
Un composant React est une fonction JavaScript qui retourne du JSX (HTML). C'est le bloc de base pour construire une interface React.

## POURQUOI ?
- Les composants divisent l'interface en petites parties réutilisables
- Chaque composant a sa propre logique et son propre rendu
- Cela rend le code plus organisé et maintenable

## COMMENT ?

### Créer un Composant Simple

```jsx
// Fonction classique qui retourne du JSX
function Welcome() {
  return <h1>Bienvenue dans React!</h1>;
}

// Ou en utilisant des flèches (arrow function)
const Welcome = () => {
  return <h1>Bienvenue dans React!</h1>;
};

// Ou version condensée avec flèches
const Welcome = () => <h1>Bienvenue dans React!</h1>;

// Exporter pour l'utiliser dans d'autres fichiers
export default Welcome;
```

### Importer et Utiliser un Composant

```jsx
// Dans App.jsx par exemple
import Welcome from './components/Welcome';

export default function App() {
  return (
    <div>
      <Welcome />   {/* On utilise le composant comme une balise HTML */}
    </div>
  );
}
```

### Le Cycle de Vie d'un Composant Fonctionnel

1. **Création**: Le composant est créé et rendu pour la première fois
2. **Affichage**: Le JSX s'affiche à l'écran
3. **Mises à jour**: Si les données changent, le composant se re-rend
4. **Suppression**: Le composant est retiré du DOM

### Nommer ses Composants

```jsx
// ✅ Bon: Commence par une MAJUSCULE
function Header() { }
function NavBar() { }
const MainContent = () => { };

// ❌ Mauvais: Commence par une minuscule (React pensa que c'est une balise HTML)
function header() { }      // ❌ Ne marchera pas
<header />                 // sera traité comme HTML, pas comme notre composant
```

### Structure d'un Composant plus Complet

```jsx
// Imports
import { useState } from 'react';

// Logique du composant
export default function UserCard() {
  // Variables et logique
  const name = "Alice";
  const role = "Developer";
  
  // Fonction helper si nécessaire
  const getGreeting = () => {
    return `Bonjour ${name}!`;
  };
  
  // Retour du JSX
  return (
    <div className="user-card">
      <h2>{name}</h2>
      <p>{role}</p>
      <p>{getGreeting()}</p>
    </div>
  );
}
```

### Composants Imbriqués

```jsx
// Composant enfant
function Button() {
  return <button>Cliquez-moi</button>;
}

// Composant parent qui réutilise Button
function Panel() {
  return (
    <div className="panel">
      <h1>Mon Panel</h1>
      <Button />          {/* On réutilise le composant Button */}
      <Button />          {/* Une deuxième fois */}
      <Button />          {/* Autant qu'on veut */}
    </div>
  );
}
```

### Fichier vs Composant

**Bonne pratique**: Un composant par fichier

```
src/
├── components/
│   ├── Header.jsx       # Contient le composant Header uniquement
│   ├── Footer.jsx
│   ├── Card.jsx
│   └── Button.jsx
├── pages/
│   ├── Home.jsx
│   └── About.jsx
└── App.jsx
```

### Réutilisabilité des Composants

```jsx
// Un composant réutilisable
function Card() {
  return (
    <div className="card">
      <h3>Mon Card</h3>
      <p>Du contenu</p>
    </div>
  );
}

// On peut le réutiliser partout
function Dashboard() {
  return (
    <div className="dashboard">
      <Card />
      <Card />
      <Card />
      <Card />
    </div>
  );
}
```

## Exemple Complet: Application Todo Simple

```jsx
// src/components/TodoItem.jsx
function TodoItem() {
  return (
    <li className="todo-item">
      <span>Faire les courses</span>
      <button>Supprimer</button>
    </li>
  );
}
export default TodoItem;

// src/components/TodoList.jsx
import TodoItem from './TodoItem';

function TodoList() {
  return (
    <ul className="todo-list">
      <TodoItem />
      <TodoItem />
      <TodoItem />
    </ul>
  );
}
export default TodoList;

// src/App.jsx
import TodoList from './components/TodoList';

export default function App() {
  return (
    <div className="app">
      <h1>Ma Todo List</h1>
      <TodoList />
    </div>
  );
}
```

## Convention de Nommage

```jsx
// ✅ Noms descriptifs et en PascalCase (majuscule au début)
function UserProfile() { }
function ShoppingCart() { }
const NavigationMenu = () => { };

// ❌ Noms trop génériques ou non descriptifs
function Component() { }
function Thing() { }
const X = () => { };
```

## Pièges Courants

❌ **Erreur**: Composant commence par une minuscule
```jsx
const welcome = () => <h1>Hi</h1>;  // ❌ Erronée

// ✅ Correct
const Welcome = () => <h1>Hi</h1>;
```

❌ **Erreur**: Oublier les parenthèses quand on utilise le composant
```jsx
// ❌ Mauvais - On appelle juste la fonction, pas un composant
<App>    {/* Wrong if we forgot parentheses in definition */}

// ✅ Correct
<App />
```

❌ **Erreur**: Retourner plusieurs éléments sans fragment
```jsx
function MyComponent() {
  return (        // ❌ Erreur: deux éléments sans wrapper
    <Header />
    <Content />
  );
}

function MyComponent() {
  return (        // ✅ Correct: utilisé Fragment
    <>
      <Header />
      <Content />
    </>
  );
}
```

## À Retenir ✨

- ✅ Un composant est une fonction qui retourne du JSX
- ✅ Les noms commencent TOUJOURS par une MAJUSCULE
- ✅ On importe et on utilise les composants comme des balises HTML `<MonComposant />`
- ✅ Un fichier = un composant (meilleure pratique)
- ✅ Les composants peuvent être réutilisables
- ✅ On peut imbriquer les composants les uns dans les autres
