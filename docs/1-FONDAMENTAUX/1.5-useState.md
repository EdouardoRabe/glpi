# 1.5 - useState (État Reactif)

## QUOI ?
`useState` est un Hook React qui permet à un composant d'avoir une "mémoire". C'est comment on crée des données qui changent et qui mettent à jour l'affichage quand elles changent.

## POURQUOI ?
- Les props sont statiques (ne changent pas)
- Avec `useState`, on peut avoir des données **dynamiques**
- Quand l'état change, le composant se re-rend automatiquement

## COMMENT ?

### Syntaxe Basique de useState

```jsx
import { useState } from 'react';

function Counter() {
  // useState retourne une paire: [valeur, fonction pour la modifier]
  const [count, setCount] = useState(0);
  
  return (
    <div>
      <p>Compte: {count}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
    </div>
  );
}
```

**Explication:**
- `useState(0)` = initialiser l'état à 0
- `count` = la valeur actuelle de l'état
- `setCount` = la fonction pour changer l'état
- Quand on appelle `setCount(valeur)`, React re-rend le composant

### Plusieurs États dans un Composant

```jsx
function UserForm() {
  const [name, setName] = useState('');
  const [age, setAge] = useState('');
  const [email, setEmail] = useState('');
  
  return (
    <form>
      <input 
        value={name} 
        onChange={(e) => setName(e.target.value)}
        placeholder="Nom"
      />
      <input 
        value={age} 
        onChange={(e) => setAge(e.target.value)}
        placeholder="Âge"
      />
      <input 
        value={email} 
        onChange={(e) => setEmail(e.target.value)}
        placeholder="Email"
      />
      
      <p>Infos: {name}, {age} ans, {email}</p>
    </form>
  );
}
```

### État avec Objet

Pas besoin de plusieurs useState, on peut utiliser un objet:

```jsx
function UserForm() {
  const [user, setUser] = useState({
    name: '',
    age: '',
    email: ''
  });
  
  const handleChange = (field, value) => {
    // Important: on doit créer un NOUVEL objet
    setUser({
      ...user,                    // On copie les valeurs existantes
      [field]: value             // On change juste celle demandée
    });
  };
  
  return (
    <form>
      <input 
        value={user.name} 
        onChange={(e) => handleChange('name', e.target.value)}
        placeholder="Nom"
      />
      <input 
        value={user.age} 
        onChange={(e) => handleChange('age', e.target.value)}
        placeholder="Âge"
      />
      
      <p>Infos: {user.name}, {user.age} ans</p>
    </form>
  );
}
```

### État avec Listes (Arrays)

```jsx
function TodoList() {
  const [todos, setTodos] = useState(['Faire les courses', 'Appeler maman']);
  
  const addTodo = (newTodo) => {
    setTodos([...todos, newTodo]);  // Ajoute un nouvel élément
  };
  
  const removeTodo = (index) => {
    setTodos(todos.filter((_, i) => i !== index));  // Supprime à l'index
  };
  
  return (
    <div>
      <ul>
        {todos.map((todo, index) => (
          <li key={index}>
            {todo}
            <button onClick={() => removeTodo(index)}>Supprimer</button>
          </li>
        ))}
      </ul>
      <button onClick={() => addTodo('Nouvelle tâche')}>Ajouter</button>
    </div>
  );
}
```

### Contador avec Opérations

```jsx
function Counter() {
  const [count, setCount] = useState(0);
  
  const increment = () => setCount(count + 1);
  const decrement = () => setCount(count - 1);
  const reset = () => setCount(0);
  
  return (
    <div className="counter">
      <h1>{count}</h1>
      <button onClick={increment}>+</button>
      <button onClick={decrement}>-</button>
      <button onClick={reset}>Reset</button>
    </div>
  );
}
```

### Fonction Initialiser

Au place d'une valeur, on peut passer une **fonction** à `useState`:

```jsx
function ExpensiveComponent() {
  // Si la valeur initiale est coûteuse à calculer:
  const [count, setCount] = useState(() => {
    console.log('Calcul initial...');
    return 0;  // La fonction est appelée UNE FOIS au démarrage
  });
  
  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>+</button>
    </div>
  );
}
```

## Exemple Complet: Lampe Interactif

```jsx
function Lamp() {
  const [isOn, setIsOn] = useState(false);
  
  const toggleLamp = () => {
    setIsOn(!isOn);  // Inverser la valeur
  };
  
  return (
    <div className={`lamp ${isOn ? 'on' : 'off'}`}>
      <div className="bulb"></div>
      <button onClick={toggleLamp}>
        {isOn ? 'Éteindre' : 'Allumer'}
      </button>
      <p>La lampe est {isOn ? 'ALLUMÉE ✨' : 'éteinte'}</p>
    </div>
  );
}
```

## Exemple Complet: Liste de Courses

```jsx
import { useState } from 'react';

function ShoppingList() {
  const [items, setItems] = useState(['Lait', 'Pain', 'Œufs']);
  const [input, setInput] = useState('');
  
  const addItem = () => {
    if (input.trim() === '') return;
    setItems([...items, input]);
    setInput('');  // Vider l'input après ajout
  };
  
  const removeItem = (index) => {
    setItems(items.filter((_, i) => i !== index));
  };
  
  return (
    <div className="shopping-list">
      <h2>Ma Liste de Courses</h2>
      
      <input 
        value={input}
        onChange={(e) => setInput(e.target.value)}
        placeholder="Ajouter un article..."
        onKeyPress={(e) => e.key === 'Enter' && addItem()}
      />
      <button onClick={addItem}>Ajouter</button>
      
      <ul>
        {items.map((item, index) => (
          <li key={index}>
            {item}
            <button onClick={() => removeItem(index)}>❌</button>
          </li>
        ))}
      </ul>
    </div>
  );
}
```

## Pièges Courants

❌ **ERREUR**: Modifier l'état directement
```jsx
// ❌ MAUVAIS - React ne détecte pas le changement
const [count, setCount] = useState(0);
count = count + 1;  // WRONG!

// ✅ BON - Utiliser setCount
setCount(count + 1);
```

❌ **ERREUR**: Oublier les crochets dans useState
```jsx
// ❌ Mauvais
const [name] = myHook();

// ✅ Correct
const [name] = useState('');
```

❌ **ERREUR**: Utiliser useState dans une boucle
```jsx
// ❌ MAUVAIS - Ne jamais faire ça!
for (let i = 0; i < 3; i++) {
  const [count, setCount] = useState(0);
}

// ✅ Utiliser un array à la place
const [counts, setCounts] = useState([0, 0, 0]);
```

❌ **ERREUR**: Oublier le spread operator pour les objets
```jsx
const [user, setUser] = useState({ name: 'Alice', age: 28 });

// ❌ Mauvais - Écrase tout
setUser({ name: 'Bob' });  // age disparaît!

// ✅ Bon - Utiliser spread
setUser({ ...user, name: 'Bob' });
```

## À Retenir ✨

- ✅ `useState` = la façon de créer un état réactif
- ✅ Toujours importer: `import { useState } from 'react'`
- ✅ `const [value, setValue] = useState(initialValue)`
- ✅ Quand l'état change, le composant se re-rend
- ✅ Ne jamais modifier l'état directement
- ✅ Pour les objets/arrays, créer une nouvelle copie avec spread `...`
