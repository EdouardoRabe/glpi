# 1.5 - Rendu Conditionnel (Affichage Conditionnel)

## QUOI ?
Le rendu conditionnel est la pratique d'afficher ou masquer des éléments JSX basé sur une condition. C'est afficher différentes choses en fonction de l'état ou des props.

## POURQUOI ?
- Afficher/masquer des éléments selon un état
- Afficher différents messages selon l'authentification
- Créer des interfaces dynamiques
- Gérer les états de chargement, erreur, succès

## COMMENT ?

### Opérateur Ternaire (⭐ LA MEILLEURE OPTION)

```jsx
import { useState } from 'react';

function LoginStatus({ isLoggedIn }) {
  return (
    <div>
      {isLoggedIn ? <p>Bienvenue!</p> : <p>Veuillez vous connecter</p>}
    </div>
  );
}

// Utilisation
<LoginStatus isLoggedIn={true} />   // Affiche: "Bienvenue!"
<LoginStatus isLoggedIn={false} />  // Affiche: "Veuillez vous connecter"
```

### Opérateur ET (&&) - Pour Afficher OU Rien

```jsx
function Notifications() {
  const [count, setCount] = useState(0);
  
  return (
    <div>
      {count > 0 && <span className="badge">{count}</span>}
      Notifications
    </div>
  );
}

// Si count > 0, affiche le badge
// Si count = 0, affiche rien
```

**ATTENTION**: Ne pas utiliser `0` ou `false` directement:

```jsx
const [count, setCount] = useState(0);

// ❌ Affichera "0" à l'écran!
{count && <p>You have {count} messages</p>}

// ✅ Correct
{count > 0 && <p>You have {count} messages</p>}
```

### Conditions if/else Classiques (Hors du JSX)

```jsx
function AuthComponent() {
  const [isLoggedIn, setIsLoggedIn] = useState(false);
  
  let content;
  
  if (isLoggedIn) {
    content = <div><h1>Dashboard</h1></div>;
  } else {
    content = <div><h1>Page de Login</h1></div>;
  }
  
  return content;
}
```

### Switch Statement

```jsx
function UserRole({ role }) {
  let message;
  
  switch (role) {
    case 'admin':
      message = <p>Accès Administrateur</p>;
      break;
    case 'user':
      message = <p>Accès Utilisateur</p>;
      break;
    case 'guest':
      message = <p>Accès Invité</p>;
      break;
    default:
      message = <p>Rôle inconnu</p>;
  }
  
  return message;
}

// Utilisation
<UserRole role="admin" />   // Affiche: "Accès Administrateur"
<UserRole role="user" />    // Affiche: "Accès Utilisateur"
```

### Variable pour Rendre du Contenu Complexe

```jsx
function ShoppingCart({ items }) {
  let content;
  
  if (items.length === 0) {
    content = <p>Votre panier est vide</p>;
  } else if (items.length === 1) {
    content = <p>Vous avez 1 article</p>;
  } else {
    content = (
      <div>
        <p>Vous avez {items.length} articles</p>
        <ul>
          {items.map(item => <li key={item.id}>{item.name}</li>)}
        </ul>
      </div>
    );
  }
  
  return content;
}
```

## Exemple Complet: Gestion des États (Chargement, Erreur, Succès)

```jsx
import { useEffect, useState } from 'react';

function DataFetcher() {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);
  
  useEffect(() => {
    fetch('https://api.example.com/data')
      .then(res => res.json())
      .then(data => setData(data))
      .catch(err => setError(err.message))
      .finally(() => setLoading(false));
  }, []);
  
  // États exclusifs: une seule condition est vraie
  if (loading) {
    return <p>⏳ Chargement...</p>;
  }
  
  if (error) {
    return <p>❌ Erreur: {error}</p>;
  }
  
  return (
    <div>
      <h2>✅ Données Chargées</h2>
      <p>{data}</p>
    </div>
  );
}
```

## Exemple Complet: Formulaire avec Validation

```jsx
import { useState } from 'react';

function LoginForm() {
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [error, setError] = useState('');
  
  const handleSubmit = (e) => {
    e.preventDefault();
    
    // Validation
    if (!email.includes('@')) {
      setError('Email invalide');
      return;
    }
    
    if (password.length < 6) {
      setError('Mot de passe trop court');
      return;
    }
    
    setError('');
    alert('Connexion réussie!');
  };
  
  return (
    <form onSubmit={handleSubmit}>
      <input 
        type="email"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
        placeholder="Email"
      />
      
      <input 
        type="password"
        value={password}
        onChange={(e) => setPassword(e.target.value)}
        placeholder="Mot de passe"
      />
      
      {/* Afficher l'erreur si elle existe */}
      {error && <p style={{ color: 'red' }}>{error}</p>}
      
      <button type="submit">Se Connecter</button>
    </form>
  );
}
```

## Astuces & Bonnes Pratiques

### Element Peut Être Null

```jsx
function Component() {
  let element = null;
  
  if (condition) {
    element = <div>Ceci s'affiche</div>;
  }
  
  return element;  // Retourner null c'est ok
}
```

### Utiliser des Constantes pour les Conditions

```jsx
function Component({ status }) {
  const isLoading = status === 'loading';
  const isError = status === 'error';
  const isSuccess = status === 'success';
  
  return (
    <>
      {isLoading && <p>Chargement...</p>}
      {isError && <p>Erreur</p>}
      {isSuccess && <p>Succès!</p>}
    </>
  );
}
```

## Pièges Courants

❌ **ERREUR**: Utiliser `0` ou `false` avec `&&`

```jsx
const count = 0;

// ❌ Affiche "0" à l'écran!
{count && <p>Vous avez {count} messages</p>}

// ✅ Correct
{count > 0 && <p>Vous avez {count} messages</p>}
```

❌ **ERREUR**: Oublier la clé dans un array de conditions

```jsx
// ❌ Mauvais: les deux buttons y'a pas les clés
{items.map(item => (
  <>
    {item.isVisible && <h2>{item.title}</h2>}
    {item.hasButton && <button>{item.buttonText}</button>}
  </>
))}

// ✅ Ajouter key aux éléments
{items.map(item => (
  <div key={item.id}>
    {item.isVisible && <h2>{item.title}</h2>}
    {item.hasButton && <button>{item.buttonText}</button>}
  </div>
))}
```

❌ **ERREUR**: Trop de ternaires imbriquées (illisible)

```jsx
// ❌ Mauvais - Très difficile à lire
{status === 'error' ? <p>Erreur</p> : status === 'loading' ? <p>Chargement</p> : <p>Succès</p>}

// ✅ Meilleur: Utiliser if/else ou switch
let message;
if (status === 'error') message = <p>Erreur</p>;
else if (status === 'loading') message = <p>Chargement</p>;
else message = <p>Succès</p>;
return message;
```

## À Retenir ✨

- ✅ Ternaire: `condition ? <A /> : <B />`
- ✅ ET: `condition && <A />` (affiche rien si false)
- ✅ IF/ELSE: Meilleur pour plusieurs cas
- ✅ SWITCH: Parfait pour les states multiples
- ✅ Attention avec `0` et `false` avec `&&`
- ✅ Toujours avoir une structure claire pour loading/error/success
