# 1.1 - Setup & Structure du Projet React

## QUOI ?
Le setup d'un projet React signifie installer les dépendances, configurer l'environnement de développement, et comprendre la structure des fichiers générés.

## POURQUOI ?
- Avoir un projet fonctionnel et prêt pour le développement
- Comprendre où placer nos fichiers et composants
- Utiliser des outils modernes comme Vite pour un développement rapide

## COMMENT ?

### Option 1 : Avec Vite (MODERNE - RECOMMANDÉ)
```bash
npm create vite@latest mon-app -- --template react
cd mon-app
npm install
npm run dev
```

### Option 2 : Avec Create React App (LEGACY)
```bash
npx create-react-app mon-app
cd mon-app
npm start
```

## Structure d'un projet React

```
mon-app/
├── node_modules/          # Dépendances installées
├── public/                # Fichiers statiques
│   └── index.html         # Fichier HTML principal
├── src/                   # CODE SOURCE (là où on travaille)
│   ├── main.jsx           # Point d'entrée
│   ├── App.jsx            # Composant racine
│   ├── components/        # Nos composants réutilisables
│   │   ├── Header.jsx
│   │   ├── Card.jsx
│   │   └── Button.jsx
│   ├── pages/             # Pages principales
│   │   ├── Home.jsx
│   │   └── About.jsx
│   ├── hooks/             # Custom hooks
│   ├── utils/             # Fonctions utilitaires
│   ├── App.css            # Styles globaux
│   └── main.css           # Styles généraux
├── package.json           # Dépendances et scripts
├── vite.config.js         # Configuration Vite
└── README.md              # Documentation
```

## Les fichiers clés

### `main.jsx`
Point d'entrée de l'application React:
```jsx
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App.jsx'

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
)
```

### `App.jsx`
Le composant principal qui contient toute l'application:
```jsx
export default function App() {
  return (
    <div className="App">
      <h1>Bienvenue dans React!</h1>
    </div>
  )
}
```

### `index.html`
La page HTML qui charge notre React:
```html
<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <title>Mon App React</title>
</head>
<body>
    <div id="root"></div>
    <script type="module" src="/src/main.jsx"></script>
</body>
</html>
```

## Package.json - Les Scripts Importants

```json
{
  "scripts": {
    "dev": "vite",              // Lance le serveur de développement
    "build": "vite build",      // Crée la version pour la production
    "preview": "vite preview"   // Prévisualise la production localement
  }
}
```

## Démarrer son premier projet

```bash
# 1. Créer le projet
npm create vite@latest mon-app -- --template react

# 2. Entrer dans le dossier
cd mon-app

# 3. Installer les dépendances
npm install

# 4. Lancer le serveur de développement
npm run dev

# Votre app est maintenant sur http://localhost:5173
```

## Pièges Courants

❌ **Erreur**: "Cannot find module 'react'"
✅ **Solution**: Faire `npm install` avant `npm run dev`

❌ **Erreur**: Les changements ne se reflètent pas
✅ **Solution**: Vérifiez que le serveur de développement tourne (`npm run dev`)

❌ **Erreur**: Port déjà utilisé sur le 5173
✅ **Solution**: 
```bash
# Tuer le processus manquant ou utiliser un autre port
npm run dev -- --port 5174
```

❌ **Erreur**: TypeError: Cannot destructure `useState`
✅ **Solution**: Faire `import { useState } from 'react'` en haut du fichier

## À Retenir ✨

- ✅ Utiliser Vite c'est plus rapide et moderne que Create React App
- ✅ Le `src/` est là où on écrit notre code React
- ✅ Les composants sont des fichiers `.jsx`
- ✅ `main.jsx` est toujours le point d'entrée de l'app
- ✅ `npm run dev` lance le serveur de développement en local
