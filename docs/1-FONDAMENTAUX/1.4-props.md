# 1.4 - Props (Propriétés)

## QUOI ?
Les Props sont des paramètres qu'on passe aux composants React. C'est comment un composant parent peut modifier le comportement d'un composant enfant.

## POURQUOI ?
- Rendre les composants réutilisables (même composant, données différentes)
- Communiquer les données du parent à l'enfant
- Éviter de répéter le code

## COMMENT ?

### Props Basiques

```jsx
// Composant qui ACCEPTE une prop (paramètre)
function Greeting(props) {
  return <h1>Bonjour {props.name}!</h1>;
}

// Utilisation du composant avec une prop
<Greeting name="Alice" />     // Affiche: "Bonjour Alice!"
<Greeting name="Bob" />       // Affiche: "Bonjour Bob!"
<Greeting name="Charlie" />   // Affiche: "Bonjour Charlie!"
```

### Destructuring les Props (Meilleure Pratique)

```jsx
// Au lieu d'utiliser props.name, on destructure
function Greeting({ name }) {
  return <h1>Bonjour {name}!</h1>;
}

// Avec plusieurs props
function UserCard({ name, age, city }) {
  return (
    <div className="card">
      <h2>{name}</h2>
      <p>Âge: {age}</p>
      <p>Ville: {city}</p>
    </div>
  );
}

// Utilisation
<UserCard name="Alice" age={28} city="Paris" />
```

### Props avec Valeurs par Défaut

```jsx
// Valeurs par défaut utiles si la prop n'est pas fournie
function Button({ text = "Cliquer ici", color = "blue" }) {
  return <button style={{ backgroundColor: color }}>{text}</button>;
}

// Utilisation
<Button />                                    // Utilise les défauts
<Button text="Ajouter" />                     // Utilise color par défaut
<Button text="Supprimer" color="red" />      // Personnalisé
```

### Passer des Objets comme Props

```jsx
const user = {
  name: "Alice",
  age: 28,
  email: "alice@example.com"
};

function UserProfile(props) {
  return (
    <div>
      <h2>{props.user.name}</h2>
      <p>{props.user.email}</p>
    </div>
  );
}

// Option 1: Passer tout l'objet
<UserProfile user={user} />

// Option 2: Destructurer dans la fonction
function UserProfile({ user: { name, email } }) {
  return (
    <div>
      <h2>{name}</h2>
      <p>{email}</p>
    </div>
  );
}
```

### Passer des Fonctions comme Props (Callbacks)

C'est très important en React! Les composants enfants peuvent appeler des fonctions du parent.

```jsx
// Composant parent
function Counter() {
  const handleClick = () => {
    alert("Bouton cliqué!");
  };

  return (
    <div>
      <h1>Mon App</h1>
      <MyButton onClick={handleClick} />
    </div>
  );
}

// Composant enfant
function MyButton({ onClick }) {
  return <button onClick={onClick}>Cliquez-moi</button>;
}
```

### Props Children - Contenu Imbriqué

```jsx
// Composant qui accepte du contenu entre ses balises
function Panel({ children, title }) {
  return (
    <div className="panel">
      <h2>{title}</h2>
      <div className="content">
        {children}        {/* C'est ce qu'on met entre <Panel> et </Panel> */}
      </div>
    </div>
  );
}

// Utilisation
<Panel title="Mon Panel">
  <p>Ceci est le contenu du panel</p>
  <button>Un bouton</button>
</Panel>

// children reçoit:
// <p>Ceci est le contenu du panel</p>
// <button>Un bouton</button>
```

### Props Conditionnelles

```jsx
// Passer une prop seulement si une condition est vraie
function Card({ showButton }) {
  return (
    <div className="card">
      <h3>Mon Card</h3>
      {showButton && <button>Cliquez</button>}
    </div>
  );
}

// Utilisation
<Card showButton={true} />     // Affiche le bouton
<Card showButton={false} />    // N'affiche pas le bouton
```

## Props Implicites (Spreading)

```jsx
const props = {
  name: "Alice",
  age: 28,
  city: "Paris"
};

// Au lieu d'écrire name={props.name} age={props.age} city={props.city}
// On peut utiliser le spread operator:
<UserCard {...props} />

// C'est équivalent à:
<UserCard name="Alice" age={28} city="Paris" />
```

## Pièges Courants

❌ **Erreur**: Modifier directement les props (React n'aime pas!)
```jsx
function Counter({ count }) {
  // ❌ Mauvais - Les props ne se modifient pas directement
  count = count + 1;
  
  return <p>Compte: {count}</p>;
}

// ✅ Correct - Utiliser useState pour les changements (voir leçon 1.5)
import { useState } from 'react';

function Counter({ initialCount = 0 }) {
  const [count, setCount] = useState(initialCount);
  
  return (
    <>
      <p>Compte: {count}</p>
      <button onClick={() => setCount(count + 1)}>+</button>
    </>
  );
}
```

❌ **Erreur**: Oublier de passer une prop requise
```jsx
// ❌ Cette fonction s'attend à avoir une prop 'name'
function Greeting({ name }) {
  return <h1>Bonjour {name}</h1>;  // undefined si name n'est pas passé
}

// ✅ Utiliser des valeurs par défaut
function Greeting({ name = "Ami" }) {
  return <h1>Bonjour {name}</h1>;
}
```

❌ **Erreur**: Passer une prop avec des tirets (pas valide en JavaScript)
```jsx
// ❌ Mauvais
<Component my-prop="value" />

// ✅ Correct (camelCase)
<Component myProp="value" />
```

## À Retenir ✨

- ✅ Les props sont comment les parents communiquent avec les enfants
- ✅ Les props sont **en lecture seule** - ne pas les modifier directement
- ✅ Destructurer les props pour un code plus lisible
- ✅ Utiliser des valeurs par défaut pour les props optionnelles
- ✅ `children` est une prop spéciale pour le contenu imbriqué
- ✅ On peut passer des fonctions comme props (callbacks)
